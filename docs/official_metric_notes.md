# Official Metric

The [Kaggle Hull metric](https://www.kaggle.com/code/metric/hull-competition-sharpe), linked from the [official Evaluation page](https://www.kaggle.com/competitions/hull-tactical-market-prediction/overview/evaluation), evaluates submitted allocations using a penalized Sharpe-related score.
Implementation: [kaggle_metric.py](../src/evaluation/kaggle_metric.py); constants and source hashes: [official_metric.yaml](../configs/official_metric.yaml).

- Allocations must be numeric and within **[0,2]**; out-of-range values raise an error rather than being clipped.
- Strategy returns combine the market allocation with the remaining cash weight at the supplied risk-free rate; leverage uses a negative cash weight.
- The base score uses the geometric daily excess-return mean divided by sample total-return std, annualized by sqrt(252).
- Volatility penalty: `1 + max(0, strategy_volatility / market_volatility − 1.20)`; **1.20 is a soft penalty threshold**, not a hard rejection.
- Return penalty: `1 + gap²/100`, where `gap = max(0, (market_geometric_excess_mean − strategy_geometric_excess_mean) × 100 × 252)`.
- Divide the base score by both penalties and cap only the upper result at **1,000,000**; exactly zero strategy or market volatility raises an error.

The official formula uses forward_returns and risk_free_rate, not market_forward_excess_returns, and adds no transaction costs or separate borrowing spread.
Its row-ID argument is unused; select scored rows and align them before evaluation.
The project preserves valid-input arithmetic and label alignment without mutating arguments; its local adapter additionally rejects malformed/nonfinite inputs.

[Synthetic reference cases](../tests/fixtures/kaggle_metric_synthetic_cases.json) and [metric tests](../tests/test_kaggle_metric.py) verify the implementation against 42 artificial cases generated by the pinned official source.
